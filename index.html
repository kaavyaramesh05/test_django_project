Academic Web Application

Academic Document Processing System

A role-based web portal designed to help students access academic documents digitally, reducing dependence on manual paperwork.

Project highlights

  • Enables students to digitally request and download mark sheets, transfer certificates and bonafide certificates.
  • Implements Student, Staff and Admin roles with separate permissions and workflows.
  • Uses Django's Model–View–Template (MVT) architecture to organize the application.
  • Includes JWT-based authentication for user sessions and API access, as implemented in the project.
  • Uses a relational database schema managed with MySQL and MySQL Workbench.
  • Uses Git and GitHub for source-code version control.
Technologies: HTML · CSS · JavaScript · Python · Django · MySQL · Git · GitHub
